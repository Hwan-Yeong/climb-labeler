# climb-labeler

클라이밍 영상의 순간을 찍는 라벨링 화면이에요. 6가지 순간을 찍어요: 양손이 시작 홀드에 · 이륙 · 탑 처음 터치 · 탑 양손 · 양손이 떨어짐 · 착지.

- 영상은 브라우저 안에서만 재생되고, 어디에도 올라가지 않아요.
- 라벨은 사용자가 연결한 GitHub 저장소(비공개 권장)의 `labels/` 폴더에 저장돼요. 연결에는 그 저장소 하나만 고른 fine-grained 토큰이 필요하고, 권한은 Contents 읽기·쓰기예요.
- 이 저장소에는 화면 파일만 있어요. 원본은 다른 곳에서 관리하고 배포 스크립트로 복사해요.
